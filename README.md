# Тестовое задание: Сквозная автоматизация учета в кондитерской

Мини-конфигурация 1С:Предприятие 8.3 для учета производства и продажи пирожных.

---

## 📋 Исходное задание

### Цель
Создать мини-конфигурацию для учета производства и продажи пирожных.
Проверить умение работать с объектами метаданных, писать запросы,
использовать механизмы проведения документов и компоновать простые отчеты.

### Раздел 1. Создание структуры данных (Метаданные)

**Справочники:**
- `Номенклатура` (Ингредиенты и Готовая продукция).
  Реквизит: `ТипНоменклатуры` (Ссылка на Перечисление).
- `Склады` (Места хранения).

**Перечисления:**
- `ТипыНоменклатуры` (Значения: `Ингредиент`, `ГотоваяПродукция`).

**Документы:**
- `ПоступлениеТоваров` (Реквизиты: `Склад`.
  ТЧ: `Номенклатура`, `Количество`, `Цена`, `Сумма`).
- `ВыпускПродукции` (Реквизиты: `Склад`, `Продукция`, `КоличествоПродукции`.
  ТЧ `Ингредиенты`: `Номенклатура`, `Количество`).

**Регистры накопления:**
- `ОстаткиМатериалов` (Вид: Остатки.
  Измерения: `Склад`, `Номенклатура`. Ресурсы: `Количество`).

### Раздел 2. Программирование алгоритмов проведения

**Документ `ПоступлениеТоваров`:**
- При проведении увеличивать (приход) остатки материалов
  или готовой продукции на указанном складе.

**Документ `ВыпускПродукции`:**
- Списывать (расход) ингредиенты из ТЧ со склада.
- Приходовать (приход) готовую продукцию (из реквизита шапки)
  на этот же склад.
- **Важно:** контроль остатков. Если не хватает ингредиента —
  документ не проводится, выводится понятное сообщение.
  Списание в рамках одной транзакции.

### Раздел 3. Работа с запросами и отчетами

**Отчёт на СКД `ОстаткиИнгредиентов`:**
- Выводить текущие остатки только для номенклатуры
  с типом `Ингредиент`.
- Поля: `Склад`, `Ингредиент`, `Количество`.
- Возможность фильтрации (отбора) по `Складу`
  в пользовательских настройках.

### Раздел 4. Дополнительное задание (на «плюс»)

**Обработка `ПоискДублейНоменклатуры`:**
- Форма содержит кнопку «Найти дубли».
- При нажатии — программный запрос находит элементы
  с одинаковым наименованием.
- Результат (список дублей + количество повторений)
  выводится в окно сообщений или в таблицу на форме.
